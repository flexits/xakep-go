(примеры для серии статей в журнале Хакер)

## Содержание

1. Go кодить! Начинаем учить Golang без скучных книжек: [статья](https://xakep.ru/2026/02/12/learning-go-1/), [код](01_intro)  
(_тулчейн, переменные и типы данных_)

2. Go сканить! Пишем простой сканер портов на Golang: [статья](https://xakep.ru/2026/03/06/go-port-scanner/), [код](02_scan)  
(_циклы и функции, немного стандартной библиотеки, файловый ввод-вывод, defer_)

3. Go парсить! Пишем парсер ARP-кеша: [статья](https://xakep.ru/2026/04/09/go-parsing/), [код](03_arp)  
(_работаем со строками, используем map, разбираем теги сборки, создаём и используем свой пакет_)

4. Go фаззить! Пишем свой сканер поддоменов, чтобы изучить многопоточность: [статья](https://xakep.ru/2026/05/22/go-subdomains/), [код](04_subdomain)  
(_введение в конкурентность: горутины, sync.WaitGroup, sync.Mutex_)

5. Go перебирать каталоги! Пишем собственный фаззер... [статья](https://xakep.ru/2026/06/26/go-directory-fuzzing/), [код](05_dirfuzz)  
(_изучаем каналы, а также знакомимся с практиками и паттернами написания кода_)

6. Go ломать хеши! Пишем свой хешкрекер... статья, [код](06_hashcracking)  
(_изучаем select, организовываем совместную работу горутин, используем профайлер для обнаружения проблем_)
